About SysKraken

One developer, a handful of small apps, and a simple rule: no ads, no tracking, nothing bundled.

Why these apps exist

I build small Android apps for my family and friends, the kind of tools I wished existed: a YouTube player that doesn't stop when the screen turns off and doesn't interrupt with ads, and a converter that saves a song or video straight to the phone without a sketchy website in between.

Once they worked well at home, it made sense to share them. Everything here is free, and the source code for every app is public, so anyone can see exactly what it does.

Why you can trust the downloads

Installing apps from outside the Play Store should come with good reasons. Here are mine.

  1. 1

    Open source

    Every app's full code is on GitHub. Nothing hidden, nothing obfuscated.

    See the code
  2. 2

    Signed releases

    Each app is signed with the same key every release, so updates install over the old version and nobody else can pass off a fake update.

  3. 3

    Nothing tracked

    No accounts, no analytics, no ads. Your history, subscriptions and downloads stay on your phone.

  4. 4

    Straight from GitHub

    Downloads come directly from each app's GitHub release, and the apps update themselves from there.

Found a bug? Have an idea?

Open an issue on the app's GitHub page: Streamo or FCon. In FCon you can also use Report an issue in the menu.
